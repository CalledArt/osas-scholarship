# Auth

## Student registration starts with verified CvSU Google identity
Students sign in only through GoogleSignInController. Verify the Google ID token server-side (signature, aud, iss, expiry, email_verified), require an exact @cvsu.edu.ph email and signed hd=cvsu.edu.ph, and identify accounts by Google sub. New students receive a 15-minute server-side pending registration session; /register GET and POST require it. Create a passwordless student account only after validated student details are submitted, using email, google_id and role from server-controlled values. Existing students sign in directly. There is no roster import or access list: the registration form is what puts a student on the admin Student Roster. Never allow student password login, arbitrary email edits, or Google login into a staff account. Data is stored via the existing Laravel User model in the Supabase PostgreSQL users table, not Supabase Auth. Tests use signed tokens with a local JWKS handler.

## Test students sign in and apply only on a local machine
The only exception to "students sign in only with CvSU Google" (decided 2026-10-24). The 20 hardcoded accounts in App\Support\TestStudents (test.studentNN@example.com, password TestStudents::PASSWORD = "michael") sign in on the ordinary password form. LoginRequest lets a student through only when TestStudents::maySignInWithPassword() is true, which requires app()->isLocal(). A real student is refused even locally, and everyone is refused on the live site (Dockerfile.vercel sets APP_ENV=production). Also only locally, posting a scholarship runs App\Actions\ApplyTestStudents, which inserts a pending application for every test student User::mayApplyTo allows, up to the slots, with no documents. Never run it on the live site, where the applications would take real students' slots. The login page never lists the accounts or the password (the local-only Test accounts box was removed 2026-10-27 at the user's request); the accounts still sign in locally. DatabaseSeeder creates them via TestStudentsSeeder, never a migration, and adds no scholarships or applications. The earlier one-click dropdown (TestStudentSignInController) was removed in favour of the password form. Tests that switch env to local or production must also call withoutMiddleware(PreventRequestForgery::class), since Laravel skips CSRF checks only in the testing environment.
